# Checklist de requisitos — configuración masiva

- [ ] Un revisor distinto del implementador confirma el alcance y los casos límite.
- [ ] La selección está limitada a 100 unidades y deduplica códigos.
- [ ] Activos y archivados tienen tratamiento visible y seguro.
- [ ] Preflight y aplicación usan revisiones esperadas e idempotencia.
- [ ] El contrato conserva URL permanente, etiqueta y auditoría por unidad.
- [ ] Se documenta la evidencia de pruebas contra Supabase local/staging.
