# Types

Contratos compartidos por API, dashboard y paquetes de ParaHoy: mensajes, tenant, conversación, draft, orden, menú, perfiles de restaurante y negocio ligero, Dynamic Links paginados y respuestas del concierge. Los tipos de perfil y destino `profile` viven aquí; el dashboard no redefine contratos de Dynamic Links.

Los tipos representan contratos runtime compartidos; las reglas de negocio permanecen en backend/core y los tipos puramente visuales en el feature frontend correspondiente.
